# 暗黑神王：功法页 + 战令页重构

## 功法页（角色 → 功法）

### 症状与根因
- **「页面完全空白，只剩 5 条竖线」**：格子内部又嵌套了一层 `height="100%"` 的内层容器，Yoga 高度链在此塌陷为 0，格子无高度，只剩边框线。
- **修法**：改为单层 `width="23%" + aspectRatio = 1` 正方形格，`flexShrink = 0`，左右 `padding = 3`；每行 4 格，`flexWrap = "wrap"`。
- **数据读不全**：`Data.Skills` 共 42 条，原先按 `CanUseSkill` 过滤后只剩 6 条。改为按职业 `classId` 过滤，未解锁的流派技能也建格（灰锁态），信息完整不丢。

### 视觉与交互
- 每格用 `UI.Icon("skill_" .. key)` 取真实技能图。
- 边框按阶数着色：1–3 蓝、4–6 紫、7–10 橙、变异红，并配同色外发光。
- 右下角 `Lv.x` 徽标；变异技能左上「异」角标；未解锁整格灰罩 + 锁。
- 点击任一格 → 底部半屏抽屉（`V2.OpenSheet` 范式），含技能描述、冷却、熟练度进度条，以及「升级 / 使用残卷 / 神石变异」大按钮。

## 战令页（season）

### 路由修复（关键）
- 战令页一度仍显示旧 `PassPanel`：因为 `Panels.lua` 的 `V2PAGES` 里没有 `season` 键，且旧代码把 `season → vip` 重定向。
- 修法：删除 `season→vip` 重定向，`V2PAGES["season"] = V4.BuildPass`，早分派生效，旧实现自然失效（同 cfdc114c 的早分派机制）。补丁脚本 `tools/patch_season_route.py`。

- **赛季大卡**：168 高金色光效卡「第 1 赛季 · 初锋新兵」；30 高金色流光进度条「战令等级 1 / 100」。

## 全局缺陷：切图里烘焙了文字
- 根因：所有面板共用的 `mir_btn_gold / mir_btn_dark / mir_btn_cancel / mir_tab_on / mir_tab_off` 这 5 张切图**把「确定 / 取消 / 新建」烘焙进了像素**，任何按钮文字都会与之糊叠（影响 38 处调用点，按文件统计见 CarnivalV2 7、EscortV2 9、VipV2 6、MapV2 4 等）。
- 修法一（`tools/make_plain_buttons.py`）：重生成无任何文字的金属渐变纯底板，原图备份到 `tools/skin_backup/`。
- 修法二（`tools/fix_nav_flat.py`）：底栏本体改用纯色背板 + 金边，不再依赖带装饰切图，只改一处 `bottomNav` 即让「返回/功法/天赋/被动」清晰可读。
- 教训：**切图只放材质与边框，文字必须由 UI 层绘制**；发现文字糊叠先查图片本身是否烘焙了文案。
